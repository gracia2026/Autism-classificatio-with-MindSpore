# Autism-classification-with-MindSpore and ModelArts
# This project is designed to be a tutorial for Master of Science in Artificial Intelligence course students.
# The students have different educational backgrounds but are excited to learn and apply Machine/Deep learning models through different platforms supported by Industries.
# Majority of the class has limited to nil working knowledge or experience on the Cloud platform.
# Hence the first class introduces them to machine learning techniques with demonstration.
# The second class is an asynchronous educational video on independent learning by migrating to the cloud platform using ModelArts console. 
# This project comprises of a single 'Experiment 1 file' that contains the Development Evnviroment setup, classification on structured .csv data, clustering and classification on image data,and visualization of results on local PC. It concludes with the steps to migrate to cloud and visualize the scalability and performance improvement.
#  Installation of all packages is given as an Environment Setup and Software Package Installation File.
# Screenshots and additional educational video is included for the Cloud platform demonstration for Autism classification.
